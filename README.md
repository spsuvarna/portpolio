# Uduvra Labs portfolio

A responsive, single-page portfolio for Sumanth Suvarna's independent software practice in Udupi.

## Preview

Open `index.html` directly in a browser, or run a small local server from this directory:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Before publishing

The contact details in `script.js` were populated from the supplied résumé. Confirm that they are the details you want to make public. Also consider replacing the stylized “S” portrait in the About section with a professional photograph after you have one.

## Publishing options

This static website can be published free on GitHub Pages, Cloudflare Pages, Netlify or Vercel. A custom domain can be connected later.

## Brand note

“Uduvra Labs” is a coined working brand name inspired by Udupi and Suvarna. Broad exact-name web searches and DNS checks on 13 November 2026 found no obvious public use or active DNS for `uduvra.com`, `.in`, `.tech` or `.dev`. This is not legal clearance or proof that a domain is unregistered. Check registrar availability, MCA company-name availability and the Indian Trade Marks Registry before registration or significant spending.
